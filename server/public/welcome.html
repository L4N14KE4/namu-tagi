나무타기

최근 버전: v0.1.0

나무타기에 오신 걸 환영해요.
링크를 하나씩 눌러 나무위키 문서 사이를 올라가는 게임이에요.[1]
부담 없이 한 판 해 보세요.

도전장을 받아서 오셨다면 도전장 탭으로 돌아가 주세요.
돌아가면 바로 도전할 수 있어요.

1. 첫 판 시작하기 2. 게임 규칙 3. 더 즐기기

1. 첫 판 시작하기

  1. 주소창 오른쪽 퍼즐 조각 아이콘을 눌러 나무타기를 고정해요.
    툴바에서 언제든 바로 열 수 있어요.
  2. 툴바의 나무타기 아이콘을 눌러요.
  3. 오늘의 문제 풀기를 눌러요.
    문제가 새 탭으로 열려요.
  4. 카운트다운이 끝나면 시간이 흘러요.
    본문 링크만 눌러 목표 문서까지 가요.

이미 열어 둔 나무위키 탭은 새로고침해 주세요.
새로고침하면 그때부터 나무타기가 동작해요.

2. 게임 규칙

  • 게임 중에 다른 탭이나 창으로 가면 경고가 떠요.
    한 번 더 가면 실격이에요.
  • 검색창과 찾기(Ctrl+F)는 쓸 수 없어요.
  • 뒤로가기는 쓸 수 있고 1단계로 세요.
    규칙에서 뒤로가기 금지를 켜면 막혀요.

3. 더 즐기기

직접 출제, 무작위 문제, 규칙 옵션, 친구에게 보내는 도전장도 있어요.
자세한 내용은 나무타기 소개에서 볼 수 있어요.

[1] 나무타기는 나무위키 및 umanle S.R.L.과 관계없는 비공식 게임이에요.
