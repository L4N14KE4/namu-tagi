# 나무타기 프로토타입

나무위키에서 시작 문서부터 목표 문서까지 **본문 링크만** 눌러 도달하는 게임. 서버·계정 없음. 기록은 내 브라우저에만 남는다.

## 설치 (개발자 모드)

1. 크롬에서 `chrome://extensions` 를 연다.
2. 오른쪽 위 **개발자 모드**를 켠다.
3. **압축해제된 확장 프로그램을 로드합니다** → 이 `extension` 폴더 선택.
4. 코드를 고친 뒤에는 나무타기 카드의 새로고침 버튼을 누른다. 이미 열려 있던 나무위키 탭은 그 탭도 새로고침해야 새 코드가 붙는다. 새로고침하지 않으면 팝업이 50% 어둡게 덮이고 "연결이 끊겼어요" 안내와 **탭 새로고침** 버튼이 뜬다. 버튼을 누르면 탭을 새로고침하고 다시 연결한다.

## 게임 방식

설치하면 환영 페이지(`welcome.html`)가 새 탭으로 전체 화면에 열린다(0.33.0, `background.js`의 onInstalled가 설치(install) 때만 연다. 확장 새로고침이나 업데이트에서는 안 뜬다). 크롬은 설치할 때 이미 열려 있던 나무위키 탭에 확장을 넣지 않아서 그 탭의 안내 창에 기대지 않고 확장 자신의 페이지로 보여 준다. 부드러운 말투의 소개, 나무 그림과 줄마다 붙은 아이콘, "이미 열어 둔 나무위키 탭은 새로고침해 주세요" 안내와 **나무위키로 가기**, **닫기** 두 버튼이 있다. 어느 버튼을 눌러도 설명을 본 것으로 저장돼(introSeen) 아래 안내 창과 팝업의 첫 설명이 또 뜨지 않는다. 탭 X로 그냥 닫으면 저장되지 않으니, 처음 나무위키에 들어갔을 때 게임 설명이 화면 가운데에 한 번 뜬다(`intro.js`, 팝업의 **?** 와 같은 글). **확인** 을 누르면 팝업은 처음 열 때 설명을 띄우지 않는다. 설명은 팝업의 오른쪽 위 **?** 로 언제든 다시 보고, 나무위키 주소 끝에 `#ng-intro` 를 붙여 열어도 안내 창이 다시 뜬다. 툴바 아이콘으로 팝업을 연다. **기록** 은 지난 판의 통계다.

팝업은 **오늘의 문제**, **직접 출제**, **무작위** 순서의 탭이고 늘 오늘의 문제부터 열린다.
- **직접 출제**: 시작·목표 문서를 정한다. 비우면 시작은 나무위키 랜덤 문서, 목표는 단어 목록에서 뽑는다. 나무위키 탭에서 열면 문서 이름을 칠 때 나무위키 검색창과 같은 추천이 뜨고(팝업이 열린 동안 페이지 검색창은 빈 칸으로 보인다), **이 문서로** 는 지금 보는 문서를 채운다. 시작과 목표가 같으면 바로 막는다.
- **무작위**: 난이도(쉬움·보통·어려움, 보라색 🎲 랜덤; 목표 문서로 들어오는 링크 수 기준이라 팝업 설명도 "들어오는 링크가 많은/적당한/적은 문서"로 적는다)만 고르면 목표를 뽑고 시작은 랜덤 문서로 정한다. 게임 중 **새 문제**(3초 안에 한 번 더 눌러야 함)로 시작·목표를 둘 다 새로 뽑아 시간·경로를 0으로 처음부터 한다(한 번도 이동하지 않은 판은 기록하지 않고, 이동한 뒤에 버리면 "다시 시작함" 진 판으로 남음). 최근 나온 단어는 피한다. 도전장으로 연 판에서는 쓸 수 없다. 🎲 랜덤(0.28.0)은 목표도 나무위키 /random으로 뽑는다(숨은 iframe, 역링크 10 미만이면 8번까지 다시 뽑음). 도달 가능 여부는 보장이 없다. 카운트다운 화면 위쪽에 `시작 → 목표`를 고정으로 보여 준다(0.29.0; 랜덤은 목표를 찾는 동안 `?`).
- **오늘의 문제**: 한국 시간 날짜마다 모두에게 같은 시작·목표가 나온다. 미리 뽑아 둔 문제표는 없고, 2026-10-25를 1로 센 날짜 번호를 씨앗으로 무작위 모드 목록(`words.js`)의 보통 구간(역링크 677~1614개) 문서 889개에서 그날 문제를 계산한다(서버 없음, 별도 목록 파일 없음, 0.32.7). 쉬운 문서로는 너무 싱겁게 풀려서 뺐다. 허브 목록과는 상관없다. 목록은 정렬한 집합으로만 쓰고(파일 안 순서는 상관없음) 고정 씨앗으로 섞어 순서 Q를 만든다. 목표는 Q를 바퀴(889일)마다 다시 섞은 순서대로 하루에 하나씩 쓰고(한 바퀴 동안 같은 목표가 안 나온다), 시작은 Q에서 목표 위치로부터 s칸 뒤 문서이며 s는 바퀴마다 1, 2, 3…으로 커진다. 그래서 같은 (시작, 목표) 쌍도 뒤집힌 쌍도 444바퀴(약 1081년) 동안 다시 안 나온다(0.32.6, `node scripts/check-daily.mjs`로 확인). `words.js`를 다시 만들어 보통 구간이 바뀌면(문서를 더하거나, 역링크 수가 경계를 넘나들어 문서가 들고 나면) 그 뒤 모든 날의 문제가 바뀌므로 확장 버전이 같아야 같은 문제다. 기본 규칙 고정, 연속으로 푼 날 수를 보여 준다.
- **규칙 옵션**(직접 출제·무작위, 켜 둔 것은 그대로 기억): 
  - 뒤로가기 금지: 뒤로가기를 눌러도 실격하지 않고 원래 문서에 그대로 있는다(0.32.0). 같은 페이지 안의 뒤로가기는 나무위키보다 먼저 이벤트를 받아 멈추고 앞으로가기로 주소를 되돌린다. 전체 로드가 된 뒤로가기는 원래 문서로 다시 이동한다. "뒤로가기 금지 판이에요" 안내가 뜬다. 목차·각주를 눌러 쌓인 해시 기록으로 돌아가는 뒤로가기(같은 문서 안 이동)는 막지 않는다(0.32.10; 주소의 문서가 지금 보는 문서와 같으면 통과).
  - 틀 상자 링크 금지: 문서 어디에 있든 접는 상자("펼치기·접기" 버튼이 달린 상자와 짧은 제목 줄, 목차는 제외), "자세한 내용은 ○○ 문서를 참고하십시오" 같은 한두 줄짜리 안내 상자(문서 맨 위의 다른 뜻 안내 "○○에 대한 내용은 ○○ 문서를 참고하십시오", "여기로 연결됩니다"는 상자로 안 보이고 동음이의어 문서로 가는 길이라 뺀다), "펼치기·접기" 버튼이 있거나 `틀:` 문서로 가는 링크가 든 표, `틀:` 문서. 나무위키가 틀에서 온 상자를 표시해 주지 않아 모양으로 짐작하므로, 본문에 직접 쓴 접기 상자도 같이 막힌다.
  - 분류 링크 금지: 분류 줄과 분류 문서로 이동 불가.
  - 각주 링크 금지: 각주 목록(되돌아가기 링크 `#rfn-N`를 가진 항목) 안의 링크 불가.
  - 허브 문서 금지: `hubs.js`의 허브 문서(역링크 2000개 이상인 큰 문서 446개)로는 못 간다. 팝업의 규칙에서 허브 문서 목록을 접어서 볼 수 있다. 목표가 허브면 그 문서는 예외다. 넘겨주기 이름으로 허브에 닿으면 도착한 뒤 게임이 끝난다.
  - 같은 문서 재방문 금지: 지나간 문서로 가는 링크를 막고, 넘겨주기나 뒤로가기로 다시 닿으면 종료.
  - 제한 시간: 분 단위 숫자만, 두 자리 99분까지. 마지막 순간 누른 링크가 제한을 넘겨 도착하면 시간 초과다.
  - 최대 단계: 숫자만, 두 자리 99단계까지. 단계가 차면 진행 막대에 "3/10"으로 보이고, 그 단계까지 목표에 못 닿으면 종료. 비우거나 0이면 없음.

목표 확인: 나무위키 탭에서 연 팝업은 그 탭이 보이지 않게 목표 문서를 열어 정식 이름(넘겨주기 해소), 존재 여부, 동음이의어 여부를 보고, 동음이의어면 팝업 안에서 뜻을 고른다. 이 선택 창은 팝업 한 곳뿐이다. 나무위키가 아닌 탭(또는 새로고침하지 않은 탭)에서 연 팝업은 목표를 확인할 수 없어 직접 입력한 목표로는 시작하지 않고 안내만 띄운다. 목표를 비우는 경우, 무작위, 오늘의 문제는 어느 탭에서나 시작된다.

## 게임 중

- 화면 위 가운데 진행 막대에 목표, 단계, 1/100초 시간(제한 시간이 있으면 1분 넘게 남았을 때 "4분 35초 남음", 마지막 1분부터 "34.52초 남음"), 난이도·회차·규칙 표시, 도전 상대 기록이 보인다. 창이 좁으면(윈도우 반쪽 창, 화면 배율 125~150%) 진행 막대가 두 줄로 접히고 규칙 표시가 윗줄로 올라간다(0.32.9; 전에는 규칙을 많이 켜면 막대가 넘쳐 글자가 세로로 깨졌다). 새 문제·다시하기·그만두기 버튼은 줄이 바뀌면 남는 너비를 나눠 채운다. 난이도 표시는 팝업의 난이도 버튼과 같은 배경색이다(쉬움 초록, 보통 주황, 어려움 빨강, 랜덤 보라; 0.32.10). 밝은 테마에서는 막대 바탕(청록~초록)에 묻히지 않게 난이도 칩에 얇은 흰 테두리가 둘러진다(0.32.11, 다크에서는 없음).
- 진행 막대 밑에 한 줄 **경로**가 보인다. 지나온 문서를 막대 폭이 허락하는 만큼 모두 늘어놓고, 넘치면 앞쪽부터 …로 줄인다(지금 문서는 늘 보임). 줄을 누르면 지금까지 지나온 문서 전체가 목록으로 펼쳐진다(0번이 시작 문서). 이동할 때마다 바로 갱신되고 펼친 상태는 새로고침해도 유지된다.
- 경로와 목표 설명은 따로 켜고 끈다. 단계 옆 ≡ 버튼은 경로 줄 전체를, 목표 옆 ⓘ는 목표 설명을 여닫는다(켜진 버튼은 밝게 보인다). 경로를 끈 상태는 다음 판에도 기억한다.
- 시작하면 목표 미리보기(‘개요’ 첫 문단과 정보 상자 사진)가 막대 아래, 막대와 같은 폭으로 뜨고 첫 이동 뒤에 접힌다. ⓘ 로 다시 연다.
- 시작 문서가 다 불러와지면 화면을 50% 어둡게 덮고 "준비됐나요?", "3", "2", "1", "시작!"이 각각 따로 하나씩 나오는 카운트다운이 뜬다. 시간은 "시작!"이 뜨는 순간부터 잰다. 그 순간 어두운 배경과 위쪽 `시작 → 목표` 줄은 바로 걷히고 "시작!" 글자만 잠깐 남았다가 흐려진다(0.32.1; 전에는 시간이 가는데도 약 1.1초 동안 어두웠다). 처음 시작, 다시하기, 도전장 수락 뒤에만 나오고 새로고침으로 이어 가는 판에는 나오지 않는다. 안 보이는 탭에서는 보일 때까지 기다린다.
- 안내 문구는 문장마다 줄을 바꾸고 한글을 낱말 중간에서 끊지 않는다.
- 검색창(랜덤 버튼 포함), 실시간 검색어, 최근 변경 사이드바는 사라진다.
- 본문 안의 일반 문서·틀 문서 링크만 인정. 사이드바, 편집, 역사, 외부 링크, 없는 문서 링크는 이동하지 않고 안내만 뜬다. 문서 아래 분류 줄은 눌러서 이동할 수 있고, 분류 문서 안의 문서와 하위 분류 링크도 된다(분류는 시작·목표 문서로는 못 쓴다).
- 진행 막대의 **다시하기** 는 같은 시작·목표·규칙으로 처음부터 다시 한다(진행을 날리므로 3초 안에 한 번 더 눌러야 한다. 한 번도 이동하지 않았으면 기록하지 않고, 이동한 뒤면 "다시 시작함" 진 판으로 남는다). 카운트다운 전에 이미 사이드바와 검색창이 숨겨진 게임 화면이고, 카운트다운 동안에도 다시하기 버튼은 어둡게 보이지만(막대 폭이 시작 때 튀지 않게) 눌러지지도 스크롤되지도 않는다.
- 제한 시간이 없는 판에서 5분 동안 마우스·키보드·스크롤·터치 입력이 없으면 "아직 하고 계세요?" 창이 뜨고 시계가 멈춘다(**이어하기**, **다시하기**, **닫기**). 멈추는 시각은 마지막 입력 5분 뒤라 자리 비운 5분은 기록에 남고, 이어하기를 누르면 그 뒤부터 다시 흐른다. 닫기는 그만두기와 같다(진 판으로 기록). 창이 떠 있는 채 새로고침해도 다시 뜬다. 제한 시간이 있는 판에는 없다. 탭을 떠나 있는 동안은 자리 비움으로 세지 않는다(돌아올 때 30초 규칙이 먼저).
- 다른 탭·프로그램으로 가거나 페이지를 떠났다 돌아와도 시계는 멈추지 않는다(떠난 시간도 기록에 들어간다). 30초를 넘겨 떠나 있었으면 진 판이다. 짧게 떠난 것은 한 번만 경고 창("게임 화면을 떠났어요 / 한 번 더 떠나면 실격이에요", **계속하기**로 닫음)을 띄우고 두 번째에 "게임 화면을 너무 자주 떠났어요"로 진 판(0.32.9에서 1단계로 줄였다: 3단계, 2단계, 1단계). 다른 탭뿐 아니라 포커스가 페이지 밖으로 나간 것(옆에 놓은 다른 창을 누름, 메뉴로 연 찾기 창, 주소창, 팝업)도 똑같이 떠난 것으로 세어서, 창을 나란히 놓고 조사해도 30초·경고 규칙이 걸린다 제한 시간 판도 같다. 새로고침은 떠난 것으로 세지 않고, 경고 창은 새로고침해도 다시 뜬다. 다른 사이트에 갔다가 여러 칸 뒤로가기로 앞 문서에 돌아와도 떠난 것으로 잰다. 예전의 "이어서 하시겠어요?" 창은 없앴다(0.32.0, state.awayAt·aways·warn).
- 게임 중에 뜬 창(경고, 자리 비움, 도전장 수락) 뒤의 본문은 흐리게 가려서 미리 읽을 수 없다(0.31.2). 도전장 수락 창에는 상대 기록과 규칙만 보여 주고, **도전하기**를 누른 뒤 카운트다운을 거쳐 시간이 흐른다(0.33.5). 결과 창은 그대로.
- 새 탭 열기(보조키 클릭, 휠 클릭, 우클릭 메뉴, 드래그), 페이지 내 찾기(Cmd/Ctrl+F, 다음 찾기 Cmd/Ctrl+G와 F3, 맥의 선택한 글자로 찾기 Cmd+E), 나무위키 단축키 A/E/D는 막힌다. 찾기 키는 물리 키로 봐서 한글 입력 중이나 진행 막대 버튼을 누른 뒤에도 막힌다. 게임 중에는 링크 밖의 우클릭 메뉴와 끌기도 막힌다("Google에서 검색", "검사" 방지). 판이 끝나면 찾기를 다시 쓸 수 있다.
- 개발자 도구 단축키(F12, Cmd+Opt+I/J/C/U, Ctrl+Shift+I/J/C, Ctrl+U)도 막힌다. 메뉴로 연 개발자 도구는 `devtools.html`/`devtools.js`(manifest `devtools_page`)가 열려 있는 동안 1초마다 게임 탭에 알려서, 게임 중이면 "개발자 도구를 열었어요"로 진 판, 시작 전이면 시작하지 않는다. 게임 전에 열어 둔 개발자 도구도 잡힌다(0.32.0).
- 게임 중 포커스가 페이지 밖(브라우저 메뉴로 연 찾기 창, 주소창, 옆에 띄운 다른 창, 팝업)으로 가면 본문(`#app`)을 숨기고 가운데에 "화면을 누르면 다시 보여요"를 띄운다. 숨긴 글자는 찾기로 못 찾고, 다른 창을 옆에 두고 조사할 수도 없다. 시계는 계속 간다. 포커스가 나간 것은 떠남으로도 센다(0.32.9). 본문 속 iframe(유튜브 등)을 누른 것은 문서 안 포커스라 숨기지도 세지도 않는다(0.32.0).
- 뒤로가기·앞으로가기도 한 단계(금지 규칙이 없으면). 뒤로가기가 전체 로드가 돼도 이번 판에 지나온 문서면 한 단계다. 목차·각주 이동은 단계가 아니다. 넘겨주기는 도착 문서 기준.
- 목표는 정식 문서 이름과 정확히 같아야 도착이다.
- 새로고침은 이어 간다. 주소창 입력이나 즐겨찾기처럼 본문 링크가 아닌 방법으로 다른 문서를 열면 종료. 승인된 본문 링크 클릭이 전체 로드로 넘어간 것은 단계로 인정한다.
- 시작 전(도전장 수락 창, 카운트다운)에 주소창이나 뒤로가기로 다른 문서를 열면 그 판은 버려진다(기록 없음). 전에는 그 문서에서 판이 시작돼 목표 옆 문서에서 시작할 수 있었다(0.31.2).
- **그만두기** 는 진 판으로 기록하고 평범한 탭으로 돌아간다. 게임 상태는 탭 안에만 있어 탭을 닫으면 끝이다. 판을 시작하는 순간 "끝내지 않음"(진 판)으로 기록해 두고 끝나면 같은 기록을 결과로 바꾸므로(기록마다 `id`), 탭을 닫거나 다른 링크로 덮어써도 진 판으로 남는다(0.32.0). 확장이 업데이트돼 기록을 못 남기면 "기록을 저장하지 못했어요" 안내가 뜬다.

## 결과

- 도착하면 단계·시간·이동기록이 뜬다.
- **폭죽**(canvas-confetti): 오늘의 문제를 풀면(매번), 도전장 상대를 이기면(시간이 더 빠름, 같으면 단계가 적음), 또는 같은 문제(같은 시작·목표·규칙)를 전에 깬 적이 있고 이번 기록이 더 좋으면(단계가 적거나, 같으면 더 빠름) 화면 아래 가운데에서 위로 한 번 터진다. 기록을 깼을 때는 "내 기록을 갱신했어요 (3단계 → 2단계)" 줄이 붙는다. 그 밖의 첫 도착과 지거나 비긴 판, 모션 줄이기 설정을 켠 사용자에게는 터지지 않는다. 색은 나무위키 팔레트이고 라이트 테마에서는 안 보이는 흰색·연한 노랑을 뺀다.
- **공유하기**: 닉네임(비우면 "명랑한 다람쥐" 같은 자동 이름, 처음 한 번 정해 저장)을 정하면 "dana님이 사과 문서에서 배(과일) 문서로 1분 7.60초 만에 2단계로 이동했어요." 같은 문구와 도전장 링크가 클립보드에 복사된다. 복사하면 "복사했어요" 위에 복사한 글 그대로의 미리보기 상자가 뜬다(링크는 작고 흐리게, 한글을 풀어서 보여 준다. 다섯 줄쯤 넘으면 상자 안에서 스크롤, 0.32.3). 자동 복사가 막히면 그 자리에 직접 골라 복사할 수 있는 칸이 뜬다. 제한 규칙을 켠 판이면 문구에 "조건: 뒤로가기 금지, 제한 시간 5분"처럼 조건 줄이 붙고, 결과 카드에도 같은 조건이 보인다. 링크에 규칙이 실려 있어 받은 사람도 같은 조건으로 시작한다. 링크에 내 이름·단계·시간·경로가 담겨, 받은 사람은 링크를 열면 바로 시작하지 않고 "어디서 어디로"와 내 기록을 보여 주는 도전장 창을 먼저 본다. **도전하기** 를 눌러야 시작하고(시간도 그때부터), **취소** 하면 평범한 탭이다. 도전 중에는 진행 막대에서 내 기록을 보고, 끝나면 두 경로를 비교한다. 상대 경로는 처음엔 흐리게 가려져 있고 눌러야 보인다(재도전할 때 힌트를 보고 싶지 않을 수 있어서). 오늘의 문제는 "나무타기 10월 25일의 문제"로 시작한다(경로 이모지 줄은 0.33.1에서 뺐다). 마지막 두 줄은 "도전하려면 확장을 먼저 설치해야 해요."와 설치 링크다(확장이 없는 사람이 링크를 열면 그냥 나무위키 문서만 보여서 넣었다, 0.32.4). 설치 링크는 웹스토어 등록 전이라 `content.js`의 `STORE_URL`이 자리표시자다.
- **단계별 시간**: 지나온 문서마다 그 문서에 머문 시간(시작 문서 포함, 마지막 문서는 없음)이 목록 오른쪽에 붙는다("5.3초", 1분이 넘으면 "1분 5초"). 게임 중 경로 목록, 결과 카드의 이동기록(혼자 할 때도), 팝업 기록과 오늘의 문제 이동내역에서 보인다. 도전장 링크에도 단계별 시간(`pt`)이 실려 상대 경로 옆에도 시간이 나온다. 예전 기록에는 시간이 없어 붙지 않는다.
- **다시하기**: 같은 시작·목표·규칙으로 처음부터. 최고 기록과 통계는 팝업의 **기록**에서 본다. 기록 화면은 "규칙별로 보기"로 규칙 조합마다 따로 통계(도착률, 평균, 연속), 무작위 최고 기록, 최근 판을 보여 준다(규칙을 두 가지 이상 써 봤을 때 나타나고, 처음엔 가장 최근에 한 판의 규칙이 골라진다. "전체"로 모두 합쳐 볼 수도 있다).

## 단어 목록

`words.js`(무작위 모드와 오늘의 문제)는 `node scripts/build-words.mjs`가 만든다(오늘의 문제는 이 파일의 보통 구간 문서를 그대로 쓴다. 허브 목록과는 상관없다). `scripts/candidates.txt`의 후보마다 나무위키 문서 앞부분과 역링크 페이지를 한 번씩 받아 정식 이름, 동음이의어 여부, '문서' 이름공간 역링크 수를 읽고, 역링크 수로 셋으로 나눈다(경계는 쉬움 1615개 이상, 보통 677개 이상으로 고정이라 목록이 자라도 난이도의 뜻이 안 바뀐다). 지금은 4068개(쉬움 588, 보통 889, 어려움 2591)다. 역링크 100개 미만 문서와 동음이의어 문서는 뺐다(0.25.1에서 30개 → 100개). 0.25.0에서 위키백과 조회수와 Wikidata(링크된 언어판 150 이상)로 제안한 후보 중 사용자가 고른 것을 `candidates.txt`에 더해 늘렸다(낱자, 위키 문서, 민감 주제 11개는 뺐고 생존 인물은 넣었다). `scripts/daily-candidates.txt`와 `daily-report.json`은 처음 오늘의 문제용으로 조사한 자료로, 0.24.0에서 `candidates.txt`와 `words-report.json`에 합쳤다. 역링크는 문서가 고쳐지면 조금씩 바뀌므로 가끔(예: 한 달에 한 번) 다시 만든다. 0.27.1에서 나무위키 분류 31개(음식·스포츠·생물·작품·과학·신체·역사·사물)의 구성원 중 역링크 100 이상인 250개를 더했다(0.27.2에서 오늘의 문제용 목록도 보통 구간 714개로 다시 만들어 오늘의 문제 순서가 바뀌었다). 0.32.5에서 Wikidata(링크된 언어판 100 이상, 후보 도구는 `suggest-candidates-wikidata.mjs`)로 얇은 분야 위주 1806개를 더 조사해 871개를 더했다(생존 인물·낱자·위키 문서·언어 문서·성, 자살, 학살, 테러 단체 같은 민감 주제는 뺐다). 0.32.6에서 그때 뺐던 민감 주제까지 넣기로 해(사용자 결정) 367개를 더 조사해 243개를 더했다(3825 → 4068개). 0.32.7에서 별도 `daily.js`를 없애고 오늘의 문제가 `words.js`의 보통 구간을 그대로 쓰게 했다(`--daily` 단계도 없어짐). 후보를 늘리려면 `candidates.txt`에 줄을 더하고 `node scripts/build-words.mjs --resume`을 돌린다. 보통 구간이 바뀌면 그 뒤 오늘의 문제가 바뀐다.

## 파일

- `manifest.json` 권한은 activeTab(팝업을 연 탭의 주소)과 storage(설명창, 닉네임, 기록, 미리보기, 규칙)뿐.
- `content.js` 판정·이동 감지·진행 막대·결과·팝업 연결(자동완성, 목표 확인) 전부.
- `content.css` 게임 중인 탭에서 우회로 숨김.
- `popup.html`, `popup.js` 출제·무작위·오늘의 문제·기록·설명.
- `vendor/LICENSE-lucide.txt` 아이콘 라이선스. 환영 페이지의 줄 아이콘과 진행 막대의 ⓘ, 경로 아이콘은 Lucide(ISC, 일부는 Feather의 MIT)의 SVG를 수정 없이 인라인으로 넣었다(0.33.3). 파일을 따로 받거나 네트워크 요청을 하지 않는다. 환영 페이지의 나무 그림만 직접 그린 SVG다.
- `vendor/confetti.min.js` canvas-confetti 1.9.4(ISC, 라이선스는 `vendor/LICENSE-canvas-confetti.txt`). 크롬 웹스토어는 외부 코드를 받아 쓰는 것을 막으므로 파일을 직접 담았다.
- `scripts/suggest-candidates.mjs` 한국어 위키백과 월별 조회수 상위로 목표 후보를 제안한다(`node scripts/suggest-candidates.mjs`). 풀은 건드리지 않고 `scripts/wiki-candidates.tsv`(제목, 분야, 상위에 오른 달 수, 조회수 합, 주의)와 지금 풀과의 분야 분포만 만든다. 풀에 넣으려면 목록을 사람이 확인한 뒤 `candidates.txt`에 옮겨 `build-words.mjs`를 돌린다. 받은 응답은 `scripts/wiki-cache.json`에 남긴다.
- `scripts/suggest-candidates-wikidata.mjs` Wikidata로 목표 후보를 제안한다(`node scripts/suggest-candidates-wikidata.mjs --min-sitelinks 150`). 한국어 위키백과 문서가 있고 링크된 언어판이 N개 이상인 항목(여러 나라에서 아는 문서라 시사성이 적다)을 받아 항목의 갈래(P31)로 분야를 정하고 지금 풀과 분포를 견준다. 풀은 건드리지 않고 `scripts/wikidata-candidates.tsv`(제목, 분야, 링크된 언어판 수, 주의, 항목 번호)만 만든다. 응답은 `scripts/wikidata-cache.json`에 남긴다.
- `scripts/check-daily.mjs` 오늘의 문제 공식이 약속을 지키는지 본다(한 바퀴에 목표가 한 번씩, 쌍이 안 겹침, 목록 순서와 무관). `words.js`를 다시 만들거나 `popup.js`의 공식을 고친 뒤 돌린다(약 30초).
- `hubs.js` 허브 문서 목록(자동 생성: `node scripts/build-hubs.mjs`, 후보는 `scripts/hub-candidates.txt`).
- `intro.js` 설명(? 와 처음 설치 안내) 글과 모양. 팝업과 나무위키 안 안내 창이 같이 쓴다.
- `words.js` 무작위 모드 목표 단어 목록(자동 생성).
- `background.js` 설치하면 `welcome.html`을 새 탭으로 여는 서비스 워커(권한 추가 없음).
- `welcome.html`, `welcome.js` 설치 환영 페이지와 두 버튼. 전체 화면, 밝은/어두운 화면은 컴퓨터 설정을 따른다. 크롬 밖에서는 `e2e/popup-harness/build.py`가 만드는 `welcome-test.html`로 본다. 확장 안에서는 `chrome-extension://<확장 ID>/welcome.html` 주소로 언제든 열 수 있다.
- `devtools.html`, `devtools.js` 개발자 도구가 열려 있는 동안 게임 탭에 알리는 페이지(manifest `devtools_page`, 권한 추가 없음).

## 자동 테스트

```bash
cd ../e2e && npm install && npm run chrome && npm test
```

Chrome for Testing에 확장을 실제로 로드해 기본 흐름을 확인한다. 무작위·기록·미리보기·도전장·오늘의 문제·규칙은 아직 자동 테스트가 없고 사용자 크롬에서 손으로 확인했다.
