나무타기

나무위키 파도타기 게임

시작 문서에서 목표 문서까지, 본문 링크만 눌러 찾아가 보세요.[1]
적은 단계, 짧은 시간으로 도착하면 잘한 거예요.

1. 문제 고르기 2. 더 어렵게 하기 3. 친구와 겨루기 4. 내 기록 보기 5. 계정 없이 바로 시작해요

1. 문제 고르기

오늘의 문제하루에 하나, 모두에게 같은 문제가 나와요.
규칙도 같아서 친구와 비교하기 좋아요.
직접 출제시작 문서와 목표 문서를 직접 정해요.
나무위키 검색창처럼 문서 이름을 추천해 줘요.
무작위난이도만 고르면 시작과 목표를 대신 정해 줘요.

나무위키에서 우클릭해서 지금 문서를 시작이나 목표로 바로 넣을 수도 있어요.

2. 더 어렵게 하기

규칙을 켜면 같은 문제도 전혀 다른 판이 돼요.

  • 뒤로가기 금지, 같은 문서 재방문 금지
  • 틀 상자, 분류, 각주 링크 금지
  • 허브 문서 금지: 대한민국, 미국처럼 어디서나 닿는 문서를 못 지나가요.
  • 제한 시간, 최대 단계

게임 중에는 검색창, 랜덤 버튼, 찾기(Ctrl+F)처럼 건너뛰는 길을 막아요.
다른 탭으로 가면 경고가 뜨고, 한 번 더 가면 실격이에요.

3. 친구와 겨루기

도착하면 내 기록이 담긴 도전장 링크를 만들 수 있어요.
받은 친구는 같은 문제, 같은 규칙으로 도전해요.
시간이 빠른 쪽이 이기고, 같으면 단계가 적은 쪽이 이겨요.
상대의 경로는 이겨야 볼 수 있어요.

4. 내 기록 보기

도착률, 평균 단계와 시간, 연속 도착을 팝업에서 볼 수 있어요.
지난 판의 이동 경로와 문서마다 머문 시간도 남아요.

5. 계정 없이 바로 시작해요

기록은 내 브라우저에만 저장돼요.
도전장 링크를 만들 때만 그 판의 정보를 서버로 보내요.
자세한 내용은 개인정보처리방침을 확인해 주세요.
